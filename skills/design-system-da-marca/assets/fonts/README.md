# Fontes livres de reserva

Usadas quando a fonte do manual da marca (~/minha-marca/fontes/) não é encontrada. Todas de licença livre, com o arquivo
de licença em LICENCAS/.

| Fonte | Função | Licença |
|---|---|---|
| Instrument Serif (Regular e Italic) | Título (display) | SIL Open Font License 1.1 |
| Inter (Regular, Medium, SemiBold, Bold) | Corpo, pílulas, assinatura | SIL Open Font License 1.1 |
| Mynerve | Manuscrita | SIL Open Font License 1.1 |
| Caveat (Regular e Bold) | Manuscrita alternativa | SIL Open Font License 1.1 |

Fontes da Apple (SF Pro) e fontes "Test/Trial" NÃO podem ser redistribuídas: se a aluna quiser uma delas, ela mesma
instala no computador dela e coloca o arquivo em ~/minha-marca/fontes/ (somente se tiver direito de uso).

# Como usar esta pasta

1. Copie a pasta `minha-marca-MODELO` para a sua pasta de usuário e troque o nome para `minha-marca`.
   - Mac: fica em `/Users/SEU-NOME/minha-marca`
   - Windows: fica em `C:\Users\SEU-NOME\minha-marca`
   Ou peça: "Claude, cria a minha pasta minha-marca a partir do modelo e faz a entrevista da minha marca".
2. Preencha o `MINHA-MARCA.md` (do seu jeito) e o `marca.json` (os valores que os programas usam).
   Os textos entre [colchetes] e os valores do `marca.json` são exemplos: troque pelos seus.
3. Coloque o seu logo (`logo.png`), as suas fontes (`fontes/`), fotos (`fotos/`) e referências (`referencias/`).
4. A pasta `roteiros/` é a sua base de roteiros (passos 0 a 4). Vai crescendo sozinha.

Toda vez que você aprovar uma correção, o Claude escreve a regra no `MINHA-MARCA.md`. Com o tempo ele acerta de primeira.

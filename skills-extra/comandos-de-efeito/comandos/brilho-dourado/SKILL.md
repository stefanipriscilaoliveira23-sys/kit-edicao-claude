# /brilho-dourado

**O que faz:** sala escura, raios dourados e palavra dourada com faíscas.
**Onde combina:** resultado, conquista.
**Opções:** `text=<palavra>`, `push` (dourado = raridade: 1 por vídeo).

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py brilho-dourado <video> --start S --end E chave=valor ...
```

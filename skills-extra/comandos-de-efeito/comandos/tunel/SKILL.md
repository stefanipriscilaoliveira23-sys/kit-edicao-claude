# /tunel

**O que faz:** a imagem vira um túnel girando.
**Onde combina:** "e aí piorou", entrada de história.
**Opções:** `ratio`, `speed`, `spin`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py tunel <video> --start S --end E chave=valor ...
```

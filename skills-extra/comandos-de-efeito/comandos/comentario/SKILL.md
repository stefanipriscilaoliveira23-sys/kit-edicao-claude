# /comentario

**O que faz:** barra de comentário do Instagram digita uma palavra e publica.
**Onde combina:** chamada "comenta X".
**Opções:** `text=<PALAVRA DO CTA>` (ex.: VIRAL, CLAUDE).

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py comentario <video> --start S --end E chave=valor ...
```

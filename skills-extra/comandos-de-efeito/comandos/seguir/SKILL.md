# /seguir

**O que faz:** botão Seguir vira Seguindo.
**Onde combina:** chamada pra seguir.
**Opções:** `at=<segundo da virada>`, `x`, `y` (0 a 1), `color=<cor de destaque>`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py seguir <video> --start S --end E chave=valor ...
```

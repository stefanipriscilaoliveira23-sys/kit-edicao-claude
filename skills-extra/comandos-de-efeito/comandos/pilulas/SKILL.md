# /pilulas

**O que faz:** papel quadriculado, reels pregados atrás, cursor clicando pílulas.
**Onde combina:** checklist do que o vídeo tem.
**Opções:** `text=Gancho|Legenda|Cortes|Imagens` (pílulas com |), `images=<pasta de capas>`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py pilulas <video> --start S --end E chave=valor ...
```

# /imagem-de-apoio

**O que faz:** imagem de apoio em cima com etiqueta de preço, você embaixo.
**Onde combina:** preço, resultado, produto.
**Opções:** `images=<pasta com a imagem>`, `text=<etiqueta, ex. R$ 297>`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py imagem-de-apoio <video> --start S --end E chave=valor ...
```

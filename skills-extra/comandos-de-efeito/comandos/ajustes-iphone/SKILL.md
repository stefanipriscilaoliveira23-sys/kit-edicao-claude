# /ajustes-iphone

**O que faz:** cartão de ajustes do iPhone ligando os botões, um por frase.
**Onde combina:** lista de conquistas/hábitos.
**Opções:** `text=linha 1|linha 2|linha 3`, `ticks=<segundos com |>`, `color`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py ajustes-iphone <video> --start S --end E chave=valor ...
```

# /vidro-bento

**O que faz:** gráfico numa tela de vidro escuro atrás + blocos de vidro na frente.
**Onde combina:** resultado com número, versão painel.
**Opções:** `text`, `from`, `to` (números reais).

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py vidro-bento <video> --start S --end E chave=valor ...
```

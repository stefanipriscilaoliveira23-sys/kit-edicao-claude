# /widgets-de-vidro

**O que faz:** widgets de vidro em volta da cabeça + pílula "Editado pelo Claude".
**Onde combina:** vídeo sobre editar com Claude.
**Opções:** `text=<número grande real>`, `look=simple` pra versão de 3 widgets.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py widgets-de-vidro <video> --start S --end E chave=valor ...
```

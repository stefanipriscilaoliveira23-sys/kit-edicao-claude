# /trava

**O que faz:** páginas de texto passando com uma palavra travada numa caixa.
**Onde combina:** "todo mundo fala de X".
**Opções:** `text=<a palavra travada>`, `color=<cor de destaque>`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py trava <video> --start S --end E chave=valor ...
```

# /pontinhos

**O que faz:** a imagem se monta com pontinhos de luz.
**Onde combina:** abertura do vídeo.
**Opções:** `color=<cor de destaque>`, `cell`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py pontinhos <video> --start S --end E chave=valor ...
```

# /aproximar

**O que faz:** aproximação lenta de cinema no rosto.
**Onde combina:** momento sério, confissão.
**Opções:** `zoom` (1.6), `blur`.

Seguir o passo a passo de `~/.claude/skills/effects/COMO-USAR-COMANDOS.md` (vídeo, trecho, textos em português, conferir, renderizar, entregar).
Comando direto:

```
~/.claude/skills/effects/.venv/bin/python ~/.claude/skills/effects/scripts/aplicar.py aproximar <video> --start S --end E chave=valor ...
```
